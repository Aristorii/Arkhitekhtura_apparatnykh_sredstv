# Память: HDD vs SSD и термины DDR

## Таблица сравнения HDD и SSD

| Параметр | HDD | SSD |
|---|---|---|
| **Принцип работы** | Магнитная запись на вращающиеся пластины с помощью головок | Хранение данных во флеш-памяти (NAND), без механики |
| **Скорость чтения/записи (примерно)** | 100–200 МБ/с | SATA: 500–550 МБ/с; NVMe: 2000–7000+ МБ/с |
| **Наличие движущихся частей** | Да (шпиндель, пластины, головки) | Нет |
| **Устойчивость к ударам** | Низкая (чувствителен к тряске) | Высокая |
| **Уровень шума** | Слышимый (вращение, треск головок) | Бесшумный |
| **Цена за 1 ТБ** | Дешевле (~1 672,4-1 672,4 P) | Дороже (~4 181–6 689,6 P и выше) |
| **Срок службы / ограничения** | Ограничен механикой; ресурс TBW не критичен | Ограничен ресурсом записи (TBW) и контроллером |
| **Пример использования** | Архивы, бэкапы, медиатека, NAS | ОС, программы, игры, рабочие станции |

## Определения терминов

1. DDR
DDR — это Double Data Rate, то есть «двойная скорость передачи данных». Это тип оперативки, которая передаёт данные два раза за один такт — и туда, и обратно. Поэтому она быстрее старой памяти. Поколения: DDR3, DDR4, DDR5 — они несовместимы между собой, у них разные разъёмы

2. DIMM
DIMM — это сама планка оперативной памяти. Расшифровывается как Dual In-line Memory Module — «модуль памяти с контактами с двух сторон»

3. Ранг (rank)
Ранг — это группа чипов на планке, к которой обращаются одновременно. Планка делится на части, и контроллер работает с одной такой частью за раз. Бывают одноранговые (single-rank), двухранговые (dual-rank) планки. Чем больше рангов — тем чуть быстрее, но и нагрузка на контроллер больше

4. CAS Latency (CL)
CL — это задержка в тактах между тем, как процессор попросил данные, и тем, как память их выдала. Чем меньше CL — тем быстрее память отвечает

5. Тайминги
Тайминги — это набор задержек памяти, то есть сколько тактов надо подождать перед разными операциями. Главные: CL, tRCD, tRP, tRAS. Чем меньше тайминги — быстрее память, но не всегда стабильно работает, поэтому приходится выбирать между скоростью и стабильностью

6. Двухканальный режим
Двухканальный режим — это когда ставишь две планки памяти в специальные слоты, и они работают параллельно. Так пропускная способность удваивается. Особенно важно для встроенной графики, потому что она берёт память из ОЗУ. Чтобы работало, планки должны быть одинакового объёма и стоять в правильных слотах (обычно через один)
